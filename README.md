# cpp-notes

## 项目简介

本项目用于整理和编写 C++ 学习笔记及示例程序。目前项目仅包含基础构建配置和空的程序入口，具体内容将在后续补充。

## 项目结构

```text
.
├── CMakeLists.txt   # CMake 项目及可执行程序配置
├── compile.sh       # 配置并编译项目
└── src/
    └── main.cpp     # 当前示例程序入口
```

## 构建

需要安装 CMake 和 C++ 编译器。在项目根目录执行：

```bash
./compile.sh
```

编译产物位于 `build/` 目录。

## 后续内容

后续可在此补充各示例程序的主题、用途和运行方式。新增独立程序时，可在 CMake 配置中为其添加单独的可执行目标。
